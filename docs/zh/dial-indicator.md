# 千分表数据实时采集与记录系统

本项目是[物理实验系统](./experiment-system)的一部分。

## 项目概述

为实验室和工业环境中的数字式千分表提供一套完整的桌面端上位机软件。传统测量依赖手动记录，效率低且容易出错。本项目基于 Modbus RTU 协议实现了一款通用的数据采集软件：使用者无需编写任何串口通信脚本，就能通过图形界面快速连接设备、自动检测波特率、进行单次或连续采集、实时查看波形，并以多种格式导出数据。

主要特点：

- **自动连接**：自动扫描串口并匹配波特率，无需手动配置。
- **实时可视化**：使用高性能绘图组件，实时绘制位移变化曲线。
- **数据导出**：一键将测量数据导出为 CSV、Excel 报表或 SQLite 数据库文件。

## 项目背景

物理实验系统需要测量样本在加工过程中产生的微小位移，因此需要千分表。但采购的千分表只提供基础的 RS-485 硬件接口，没有配套的上位机软件。实验人员只能手动抄录读数，或用简陋的串口调试助手查看原始十六进制数据，既低效，也难以直观地看出位移变化的趋势（如抖动、回弹）。本项目正是为填补这一空白而开发的。

## 需求分析

**功能性需求**

- **设备控制**：支持 RS-485 串口连接，支持设备置零（Zero）。
- **数据采集**：支持单次手动读取，以及自定义频率的连续自动读取。
- **可视化**：实时滚动的位移-时间曲线，以及列表形式的历史数据。
- **数据持久化**：支持导出为 Excel、CSV 或 SQLite 格式。
- **易用性**：具备波特率自动检测，降低硬件配置门槛。

**非功能性需求**

- **响应性**：高频率串口通信时界面不能卡顿或假死（需采用多线程架构）。
- **稳定性**：能够处理串口丢包、校验错误等异常，不崩溃。
- **兼容性**：主要运行于 Windows，需要打包为独立的可执行文件。

## 技术栈

| 层 | 技术 |
|---|---|
| **硬件控制** | Python + pyserial，实现 Modbus RTU 串口通信 |
| **桌面前端** | Python + PyQt5，实现图形界面与实时波形绘制 |
| **数据后端** | Python + pandas / sqlite3，实现统计分析与多格式导出 |

## 实现与技术难点

### 硬件

| 类别 | 难点 |
|---|---|
| **开发** | 千分表使用 Modbus RTU 协议，需要手动实现指令封装、CRC16 校验以及 32 位大端序数据的解包 |
| **工程** | 设备的波特率设置不统一且未知，需要在没有文档、配置不明的情况下完成握手并建立连接 |
| **需求** | 高频率（>10 Hz）连续采集需要精确的时序控制，必须避免指令堆积造成总线冲突，同时要处理丢包等异常信号 |

### 软件

| 层 | 难点 |
|---|---|
| **硬件控制** | 波特率自动匹配算法；最小安全读取间隔的动态计算；多线程串口守护；断连检测与自动重连 |
| **桌面前端** | 基于 QThread 的多线程非阻塞界面；PyQtGraph 实时波形绘制；跨线程的信号槽通信 |
| **数据后端** | 基于 MVC 模式的业务解耦；SQLite 轻量存储；集成 pandas 的统计分析与 Excel 报表生成 |

## 用户界面

| 区域 | 说明 |
|---|---|
| **连接配置区** | 选择端口（支持自动刷新）和波特率；“自动检测”按钮可一键适配设备 |
| **操作控制区** | “单次读取”“连续读取”（可自定义间隔）“停止”“置零”四个大尺寸按钮，防止误触 |
| **实时波形图** | 基于 PyQtGraph 定制的图表控件，支持滚轮缩放、拖拽查看历史波形，Y 轴量程可自动调整 |
| **数据列表** | 实时显示“时间-数值”数据对，支持按表头排序 |
| **菜单栏** | 数据导出选项，支持 CSV、Excel 和 SQLite 数据库 |

## 项目成果

软件已打包为 Windows 安装程序并分发，在实际实验环境的多台电脑上稳定运行。它可以以 10 Hz 以上的频率流畅采集数据，在数小时的连续测试中没有出现内存泄漏或串口崩溃。导出的 Excel 报表直接用于实验数据的后期分析，明显提升了工作效率。
