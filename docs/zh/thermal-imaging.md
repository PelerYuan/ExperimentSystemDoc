# 红外热图实时传输与分析系统

本项目是[物理实验系统](./experiment-system)的一部分。

## 项目概述

为红外温感提供一套简易的配套软件：实时传输并录制红外热图，对热图上特定点的温度进行可视化分析，并导出数据，为后续的理论分析提供支持。

软件把工作流简化到最少：采集、分析、导出都在同一个简洁的界面内完成，使用者无需额外学习即可完成全部操作。

## 项目背景

物理实验系统需要记录特定加工过程中，原材料上特定点的温度变化，因此需要一套能够传输并记录红外热图的系统。

红外温感内置了局域网传输功能，但这台二手设备的管理员密码已经丢失，该功能无法使用，只能改用 USB-C 数据线传输热图。由此产生两个难题：如何把实时传输的热图保存并编码为可用的视频格式，以及如何从热图画面中读取特定点的温度。

## 需求分析

**功能性需求**

- 红外热图的实时传输与显示
- 热图视频流的编码与保存
- 热图特定点的温度分析
- 分析数据与视频的导出

**非功能性需求**

- 尽量减少硬件配置的难度，做到即插即用
- 界面简洁

## 技术栈

| 方面 | 技术 |
|---|---|
| **视频流编码** | 多线程调用 FFmpeg 流式采集，并编码为 H.264 |
| **热图分析** | OpenCV + Pillow 截取图像区域，集成 ddddocr 识别温度数值 |
| **图形界面** | Python 标准库 Tkinter，构建桌面控制窗口与交互逻辑 |

## 实现与技术难点

| 类别 | 难点 |
|---|---|
| **开发** | 二手设备的红外温感型号模糊，缺少相关文档 |
| **需求** | 自行编写软件来实时读取红外热图，没有技术支持，也没有可参考的项目，完全依靠摸索 |
| **工程** | 在复杂多变的环境中保证热图分析的正确率，优化性能占用，并处理红外温感断连等突发情况 |

## 项目成果

系统已作为物理实验系统的一部分部署在实际实验环境中（运行时长见[总览](./experiment-system#项目成果)）。最近一次检修确认，在高振动、多灰尘环境下连续使用三个月后，各项功能均正常。用户反馈，界面直观简洁，涵盖了所有功能需求。
