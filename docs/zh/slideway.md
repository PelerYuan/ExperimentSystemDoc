# 二维滑轨模块化编程控制系统

本项目是[物理实验系统](./experiment-system)的一部分。

## 项目概述

为普通用户提供一套模块化的网页编程系统，大幅降低滑轨编程的难度，让使用者可以方便地对滑轨进行初始化、归位、精确移动和设定速度移动等操作。

系统提供完整的图形化编程环境：模块化编程区、自动生成的代码区（供高级用户调试和检查）以及运行结果区。支持滑轨状态的实时监控、代码调试，以及项目的保存和导入。

## 项目背景

物理实验系统需要用钻机平台加工木材，实现精确间距钻孔等操作，因此必须有一套能够精确移动的二维滑轨系统。难点在于，如何提供一个让毫无技术背景的用户也能上手的控制界面。本项目正是为解决这一需求而开发的。

## 需求分析

**功能性需求**

- 滑轨的精确移动控制
- 完整的模块化编程功能
- 将积木程序转换并显示为代码
- 系统状态实时显示
- 项目的导出和导入

**非功能性需求**

- 与电机控制器通信时具备抗干扰能力
- 具备滑轨电机的限位保护
- 能在高振动、多灰尘的环境中长期运行

## 技术栈

| 层 | 技术 |
|---|---|
| **硬件控制** | Python + pyserial，实现串口通信 |
| **网页前端** | 原生 JavaScript + Blockly，实现模块化编程界面 |
| **网页后端** | Python + Flask，提供网页与硬件控制的 API 接口 |

## 实现与技术难点

### 硬件

| 类别 | 难点 |
|---|---|
| **开发** | 二手设备的电机控制器型号模糊，缺少相关文档 |
| **工程** | 滑轨系统自重大，接线和安装都很困难 |
| **需求** | 高比特率通信需要解决信号干扰；系统必须足够稳固，既能经受搬运时的颠簸，也能承受钻机持续的振动和灰尘 |

### 软件

| 层 | 难点 |
|---|---|
| **硬件控制** | 电机指令同步、电机坐标校准、电机分时控制、串口丢包处理、电机限位保护后的重启 |
| **网页前端** | 模块化编程界面设计；自定义代码块逻辑 |
| **网页后端** | 用户程序对电机控制 API 的调用；实时状态监控 |

## 用户界面

  <img src="../assets/slideway-ide-annotated.webp" alt="滑轨编程界面，用红框和数字标出五个区域：代码块菜单栏、模块化编程区、菜单栏、生成代码区和运行结果区" />
  <figcaption>界面分区（点击放大）</figcaption>

1. **代码块菜单栏**：提供基础的逻辑、循环、数学运算、字符串运算、变量、函数以及滑轨控制功能。
2. **模块化编程区**：从菜单栏拖拽模块并组合排列，完成编程。
3. **菜单栏**：提供项目的导出、导入和运行按钮。
4. **生成代码区**：实时显示由模块化程序生成的代码，供高级用户调试和检查。
5. **运行结果区**：根据程序运行情况，实时返回运行信息和滑轨状态。

## 项目成果

系统已作为物理实验系统的一部分部署在实际实验环境中（运行时长见[总览](./experiment-system#项目成果)）。最近一次检修确认，在高振动、多灰尘环境下连续使用三个月后，各项功能均正常。用户反馈，模块化编程界面直观简洁，涵盖了所有功能需求。
