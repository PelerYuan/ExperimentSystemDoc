# 物理实验系统总览

## 项目概览

| | |
|---|---|
| **用途** | 木材钻孔加工，并同步记录加工过程中的压力、扭矩、温度与位移 |
| **服务对象** | Lukas 博士的研究课题：不同木材加工方式对整体结构稳定性的影响 |
| **系统组成** | 工控计算机、钻机平台、二维滑轨、压力传感器、扭矩传感器、红外温感、千分表 |
| **运行状态** | 已部署使用超过 8 个月，支持 100 多场实验样本加工与数据记录 |
| **开发者** | Peler。除部分硬件采购外，系统设计、软件开发、安装调试与日常维护均由其完成 |

## 设计目标

- **集成**：所有部件都接入同一台工控计算机，统一操控，在一个工位上完成样本加工与数据采集。
- **易用**：每项功能都有图形界面（包括图形化的滑轨编程系统），并配有用户手册，使用者几乎不需要额外学习。
- **低成本**：多数部件为二手设备。缺少资料增加了开发难度，但显著节省了预算。
- **可维护**：各模块有清晰标注，接线方式与常见问题均有开发记录，便于技术人员检修。
- **稳定**：系统要在钻机造成的高振动、多灰尘环境中长期运行，实际表现见[项目成果](#项目成果)。

## 项目背景

Lukas 的博士课题需要研究不同木材加工方式对木材整体结构稳定性的影响，因此需要一套把木材加工与数据记录结合在一起的系统。钻机平台和配套的二维滑轨可以精确控制钻孔位置；安装在滑轨置物台上的压力传感器和扭矩传感器实时记录数据，供后续数学分析使用。红外温感和千分表在需要时提供红外热图分析和实时位移记录。

这套实验方案比较特别，市面上没有现成的整体解决方案。同时预算有限，多数设备是二手的，普遍缺少文档，也得不到技术支持。项目的核心难题有三个：让每个部件都能正常工作，把它们集成为统一的工控系统，并让钻机平台与二维滑轨协同运行，同时实时汇总各路传感器的数据。

## 需求分析

| 子系统 | 已知情况 | 需求 |
|---|---|---|
| **工控计算机** | 需要同时运行多款实验软件，其中红外热图分析对 CPU 要求较高 | 稳定的 Windows 10 发行版；不少于 4 GB 内存；较为现代的 CPU |
| **钻机平台** | 自带内置控制系统，但每次加工的数据需要另行测量计算 | 调整钻头高度，为二维滑轨留出足够空间 |
| **二维滑轨** | 需通过 USB 串口转换器分时控制多个电机；需承受搬运以及钻机产生的长时间高强度振动和大量灰尘 | 电机同步运行、精确移动，并封装为 API；接线与整体结构稳固；提供非技术人员也能快速上手的图形化编程界面 |
| **压力传感器** | 4 个传感器配套厂家采集器，设备型号与实际不符，接线混乱，没有可用文档，难以获得技术支持 | 提供可直接使用的上位机软件，实时传输、显示并记录数据 |
| **扭矩传感器** | 厂家提供上位机软件，但难以获得技术支持；需要独立的 220V 供电，其余通过 USB 直连电脑 | 提供可直接使用的上位机软件，实时传输、显示并记录数据 |
| **红外温感** | 内置局域网传输功能，但二手设备的管理员密码已丢失而无法使用 | 改用 USB-C 数据线（长度需满足实际布局）传输；提供上位机软件，实时传输并记录热图，支持特定点温度分析 |
| **千分表** | 厂家提供明确文档，但配套软件收费，预算内无法采购；需额外的 USB 串口转换器连接解码器与千分表 | 自研上位机软件，实时传输并显示数据；支持高频读取，并记录对应时间戳以便后期整合数据 |

  <img src="../assets/slideway-ide.webp" alt="基于积木块的滑轨图形化编程界面，左侧为代码块菜单，中间为编程区，右侧为生成的代码，下方为运行结果" />

### 红外热图实时传输与分析系统

## 设计与实施难点

| 类别 | 难点 |
|---|---|
| **设计** | 部件多而场地有限，需要在有限空间内兼顾系统的稳定、安全和易用 |
| **工程** | 场地受限，二维滑轨、钻机和工作台等大件的搬运和组装困难；钻机平台需要大功率专用插座和额外接地 |
| **需求** | 在保持整体紧凑的同时保证可维护性，并长期承受钻机带来的高振动、多灰尘环境 |
| **维护** | 压力传感器、二维滑轨等部件接线复杂，需要标注线缆及连接方式以便日后检修 |
| **软件** | 保证系统和各软件的稳定与兼容，逐一调试设备并预先配置固定参数，尽量降低使用者的学习成本 |

## 项目成果

系统已正式部署到实验环境，使用超过 8 个月，支持了 100 多场实验的样本加工与数据记录。最近一次检修是在连续使用三个月之后，未发现故障或隐患，各部件运行正常，经受住了高振动、多灰尘环境的考验。
