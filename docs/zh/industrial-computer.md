# 工控计算机系统

本项目是[物理实验系统](./experiment-system)的一部分。

## 项目概述

为实验人员提供一套软硬件解决方案，连接并控制物理实验系统中的全部硬件，使他们可以在同一台计算机上操控设备、监控状态，并完成数据的采集与分析。

## 项目背景

物理实验系统最初的设计里没有工控计算机，每次实验时临时用笔记本电脑连接所需设备。实际使用中暴露出几个问题：笔记本无处摆放，硬件连接和软件配置繁琐，实验记录也难以书写。

因此后续方案加入了工控计算机，提供无需反复更改和配置的稳定硬件环境。配套设计的工作台，同时为书写实验记录和临时摆放工具提供了台面。

## 需求分析

**功能性需求**

- 足够的硬件性能，可同时运行多款实验软件
- 足够的 USB 接口，用于连接各类硬件

**非功能性需求**

- 机箱大小合适，且需要放置在工作台上以隔绝灰尘，因此体积必须严格受限
- 控制预算
- 兼顾散热等稳定性因素，满足 7×24 小时运行

| **操作系统** | Windows 10 Enterprise 2021 LTSC |
| **系统优化** | [Chris Titus Tech's WinUtil](https://github.com/ChrisTitusTech/winutil)：关闭非必要服务并暂停系统更新 |

## 实现与技术难点

| 类别 | 难点 |
|---|---|
| **开发** | 受预算限制，全部采用廉价二手硬件，需要保证使用寿命与兼容性 |
| **工程** | 采购合适的二手硬件难度大，需要权衡价格与性能并辨别真伪 |
| **需求** | 机箱要放在工作台上隔绝灰尘，大小受到严格限制 |
| **软件** | 部分二手实验设备缺少文档和使用手册，报错只能靠经验逐个处理 |

## 项目成果

系统作为物理实验系统的一部分，已部署在实际实验环境中（运行时长见[总览](./experiment-system#项目成果)）。最近一次检修确认，在高振动、多灰尘环境下连续使用三个月后，各项功能均正常。用户反馈，与最初的方案相比，易用性明显提高，数据收集和记录更便捷，实验环境也更有条理。
